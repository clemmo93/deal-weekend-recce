# Deal — a weekend recce 🌊

A pocket guide to Deal, Kent: the best food, pubs, coffee, walks, cycling routes and
sport in and around town — on an interactive map, filterable, with one tap to Google Maps
for every spot.

**Live site:** https://clemmo93.github.io/deal-weekend-recce/

Single self-contained `index.html` (Leaflet + OpenStreetMap/CARTO tiles). Needs an
internet connection for the map tiles.
